## Editor and workflow

B1–B5: compact English control labels, help popovers, roll immediately after the import bar, settings chip, pitch-range fit, chord lane, 35% thin accompaniment behind melody, zoom-dependent labels, following playhead, collapsible mixer, one-line compare chips and collapsed note table. Mobile chord strip collapses to 44px; status is centred above transport for 2.5 seconds; disabled controls are dimmed. The loaded melody's settings chip owns BPM. MIDI entry points open the same export panel; Guitar MIDI remains a separate guitar-arrangement export.

C1–C7: optional melody track; separate bass/chord tracks; chord markers plus TXT chart; individual chord-span locks; count-in and click; validated JSON project import/export and local autosave; keyboard help via `?`. Project files contain notes, not source audio. Existing code does not provide source-audio time stretching, which remains outside this revision.

## Follow-up controls (alpha.9)

Q quantizes selected notes, or all notes with no selection, independently toward the preceding SNAP grid. Duration and metadata remain intact. FREE disables the action, floating-point triplet boundaries remain stable, and quantize participates in note Undo/Redo. The piano roll accepts the Q shortcut. Decorative SVG mask icons accompany English action labels, including dynamic controls, without changing accessible labels.

PLAY restarts from the beginning, including while already playing; STOP stops. Space toggles playback/stop and still honors explicit bar cues. Inputs and dialogs retain native keyboard behavior. Initial audio scheduling latency no longer briefly displays COUNT-IN when count-in is disabled.

`scripts/verify-quantize-browser.cjs` covers actual quantize-all/selection, preserved note lengths/velocity, Undo, Q, FREE, restart from a different cue, restart while playing, Stop, Space, typing in inputs, icons, chord-only transport and mobile Q/no overflow. Both browser scripts can target the deployed site with BASE_URL.
